# 拯救者端视频能力升级

这次升级新增 `POST /index-video`。它会在拯救者上用 ffmpeg 临时切分视频，再逐段调用 WeMM 的原生视频输入，返回每一段的起止时间和向量。

## Windows 端需要做的事

把升级包里的 `wemm_api.py` 覆盖到 Ubuntu 的 `~/wemm-radar/cloud/wemm_api.py`，然后在 Ubuntu 终端运行：

```bash
cd ~/wemm-radar/cloud
sudo apt-get update
sudo apt-get install -y ffmpeg
bash start_legion.sh
```

看到 8000 端口启动后不要关闭这个终端。Mac 素材雷达的服务地址和 API 密钥不用修改。

## 如何确认升级成功

在素材雷达设置中选择“均衡，最多12段”，保存后点击左侧“补充视频片段”。

打开任意视频详情，如果“语义索引”显示 `WeMM 视频`，说明原生视频片段能力已经启用。如果显示 `WeMM 画面` 或提示关键帧兼容索引，通常说明拯救者还在运行旧版服务，请重启 `start_legion.sh`。

## 8GB 显存建议

- 先用均衡档。
- 索引时让模型串行运行，不同时开启其他占显存的软件。
- 如果显存不足，在 Ubuntu 运行 `export WEMM_VIDEO_MAX_FRAMES=12` 后重新启动服务。
- 已经完成的片段向量保存在 Mac 浏览器，拯救者关机后仍可浏览素材，本地标签筛选也仍然可用。
