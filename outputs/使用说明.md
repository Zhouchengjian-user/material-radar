# 素材雷达助手 视频工作台版

## 已经完成

- 图片、视频批量导入与浏览器本地保存
- 图片缩略图、视频时间点抽帧
- 比例、颜色、文件名标签自动生成
- 文字、筛选条件与参考图本地检索
- 素材详情、视频跳转、标签编辑、使用次数记录
- 片段级自然语言检索与准确时间码
- 脚本逐句配镜，每句返回 3 个候选镜头
- 近似视频片段与待复用素材雷达
- WeMM-Embedding 2B 云端服务及产品连接界面
- 索引 JSON 导出

## 第一次使用

在项目目录运行：

```bash
npm start
```

浏览器打开：

```text
http://127.0.0.1:4173
```

点击“导入素材”，建议第一次准备 3 至 5 张图片和 1 至 2 段短视频。也可以直接把文件拖到页面中。

未连接 WeMM 时，产品仍然可以按文件名、颜色、比例、标签和参考图进行本地检索。

## 连接腾讯 WeMM

AutoDL 建议先选单张 24GB 或更大显存的 GPU，模型使用 `tencent/WeMM-Embedding-2B`，向量维度先选 256。

把产品包中的 `cloud` 文件夹上传到 AutoDL 后运行：

```bash
cd cloud
pip install -r requirements.txt
export WEMM_MODEL=tencent/WeMM-Embedding-2B
export RADAR_API_KEY=请换成你自己的一段随机密码
bash start_autodl.sh
```

在 AutoDL 控制台把容器端口 `8000` 映射为公网地址。回到产品，点击右上角设置图标，填写公网地址和同一段 API 密钥，先点“测试连接”，成功后保存。

## 关机后的行为

- AutoDL 关机不会删除电脑里的素材库。
- 本地筛选、标签、使用记录和参考图近似检索仍可使用。
- 自然语言语义检索会暂停。
- AutoDL 再次开机后，在 `cloud` 目录重新运行 `bash start_autodl.sh` 即可恢复。

## 视频索引档位

- 快速：最多 6 段，适合首次试用和批量粗筛。
- 均衡：最多 12 段，推荐给 RTX 5060 Laptop 8GB。
- 精细：最多 24 段，覆盖更完整，但首次索引耗时更长。

视频索引在导入时执行一次，之后搜索只比较已经保存的向量，不会每搜一句都重新跑视频。

## 当前版本的边界

- 素材只保存在当前浏览器。清理浏览器站点数据会删除素材。
- 尚未加入多账号、团队共享、对象存储和权限管理。
- 当前使用等长片段覆盖视频，还不是基于镜头边界的自动场景切分。
