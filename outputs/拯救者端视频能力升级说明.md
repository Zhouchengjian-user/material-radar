# 拯救者端视频能力升级

当前视频能力由两个服务配合完成：8000 的 `POST /index-video` 负责 WeMM 画面语义向量，8001 负责真实镜头切分、语音识别、OCR、字幕轨和长视频分块任务。网页把这些结果融合成镜头级检索单元。

## Windows 端需要做的事

把升级包里的 `wemm_api.py` 覆盖到 Ubuntu 的 `~/wemm-radar/cloud/wemm_api.py`，然后在 Ubuntu 终端运行：

```bash
cd ~/wemm-radar/cloud
sudo apt-get update
sudo apt-get install -y ffmpeg
bash start_legion.sh
```

看到 8000 端口启动后不要关闭这个终端。Mac 素材雷达的服务地址和 API 密钥不用修改。

如果尚未升级 8001，把仓库中以下提示词依次交给拯救者上的 Pi Agent：

1. `outputs/给拯救者Pi-Agent的视频近秒级精度升级提示词.md`
2. `outputs/给拯救者Pi-Agent的长视频分块断点升级提示词.md`
3. `outputs/给拯救者Pi-Agent的搜索优先队列升级提示词.md`

## 如何确认升级成功

在素材雷达设置中分别测试 WeMM 与媒体分析服务。8001 的 `/health` 应返回近秒级分析、长视频分块和动态 OCR 等能力标记；任务中心应能分别显示镜头、语音、OCR 和向量进度。

打开任意视频详情，如果“索引方式”显示 `WeMM 视频` 或“分块断点”，说明视频语义能力已经启用。如果提示关键帧兼容索引，通常说明拯救者仍在运行旧版服务或 8000 暂时不可用。

## 8GB 显存建议

- 首次批量导入可用“快速分析”，最终检索建议使用“智能精细”。
- 索引时让模型串行运行，不同时开启其他占显存的软件。
- 如果显存不足，在 Ubuntu 运行 `export WEMM_VIDEO_MAX_FRAMES=12` 后重新启动服务。
- 这里的 12 是每个视频片段的采样帧上限，不是整条视频最多 12 段。
- 已经完成的片段向量保存在 Mac 浏览器，拯救者关机后仍可浏览素材，本地标签筛选也仍然可用。
